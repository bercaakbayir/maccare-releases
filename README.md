# MacCare releases

Downloads for [MacCare](https://maccare.app), the Mac health assistant that runs on your Mac.

**[Download the latest MacCare.dmg](https://github.com/bercaakbayir/maccare-releases/releases/latest/download/MacCare.dmg)**

Needs a Mac with Apple Silicon and macOS 14 or later.

1. Open **MacCare.dmg** and drag MacCare into **Applications**.
2. Open MacCare. It lives in your menu bar; press **⌥ Space** to talk to it.

If macOS says it can't verify MacCare the first time, open **System Settings → Privacy & Security**
and click **Open Anyway**. You only need to do this once.

This repository holds release builds only. Each release lists the SHA-256 of its DMG.
